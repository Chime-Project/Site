# Chime Health — 2-step checkout, single product: GLP Squared (product → checkout)

The 1-month / 3-month checkout (`chime-checkout-2/`) with **one product and no
medication choice** — 2026-09-07 client audio, item 14: "we have one product
coming that's called GLP Squared… it's just gonna be one product option".
Generated by the same script in MODE `one`:

    cd ~/Sites/chime && python3 uploads/inv-checkout-flow/build-chime-checkout.py one

(`build-chime-checkout.py` with no argument rebuilds `chime-checkout/`, `two`
rebuilds `chime-checkout-2/`; the folders never touch each other.) Edit the
script and re-run rather than hand-editing the compiled sheets.
