The 1-month / 3-month checkout (`chime-checkout-2/`) rebuilt as a combo offer — 2026-09-08
client request: "a version that incorporates a BONUS - FREE NAD ($299 Value) … the whole offer
structure is around getting a combo with both products … emphasize that they get them both and
the benefit of getting both and it's one low price". Generated by the same script in MODE `bonus`:

    cd ~/Sites/chime && python3 uploads/inv-checkout-flow/build-chime-checkout.py bonus

(no argument rebuilds `chime-checkout/`, `two` rebuilds `chime-checkout-2/`, `one` the GLP Squared
page; the folders never touch each other.) Edit the script and re-run rather than hand-editing
the compiled sheets.
