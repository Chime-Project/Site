# chime-offer-u10 — GLP-1 full-flow clone (lander → quiz → checkout)

Branding-only clone of a competitor's full GLP-1 funnel (client sheet 2026-10-06, "RIP The Entire Flow"; Part C of
`GLP-MEMBERSHIP-AND-FLOW-RIPS-PLAN.md`, untracked). Their colours, fonts, layout, copy, prices, offer ladder, timer,
upsell sheet, ratings, stats, press strip, brand-drug cards and pre-ticked consents are kept on purpose (study copy);
only the brand is swapped. `noindex`, not in the nav.

| Page | What it is |
|---|---|
| `index.html` | Offer lander ("Commit today, Transform your tomorrow", from $49/month); every CTA → `consultation/` |
| `consultation/` | 16–20 screen intake quiz (resume, auto-advance, BMI, 18+, timeline, medical DQ review + lockout) |
| `checkout/` | "Plan approved" checkout: 10:00 timer, semaglutide / tirzepatide picker, 1/3/6/12-month ladder, one-time upsell sheet, order review, inert payment look-alike; CONTINUE → `welcome/` |
| `not-eligible/` | `?reason=state_louisiana` / `?reason=bmi_too_low` |
| `welcome/` | Their post-payment page |

**Built, not hand-written:** the pages, `css/`, `images/`, `fonts/`, `js/consultation-config.js` and
`js/consultation-screens.js` are generated by the untracked Part C build in `uploads/` (`build.py`, from live captures of
every screen with their network calls blocked). Edit the build, not the output. Hand-written: `js/lander.js`,
`js/consultation.js`, `js/checkout.js`, the tests and `js/layout-check.js`.

**Swapped:** logo (Chime logo in their logo canvases), their name in copy / alt / legal, their partner medical group →
"our partner medical group", named pharmacies → "licensed US pharmacies", support e-mail → hello@chimehealth.com, phone →
1-XXX-XXX-XXXX, LegitScript → the chimehealth.com seal, legal + company links → Chime pages, login and blog cards → `#`,
vials / box / app art → Chime vials and wordmark, people + member videos → Chime-owned stills (Higgsfield).

**No request leaves the pages** except LegitScript's hosted seal image (compliance code). No trackers, no Stripe, no
backend: the payment fields are a look-alike and nothing is sent. Fonts are self-hosted.

**No text over titles (CLAUDE.md §4c):** Health Guide labels and How-it-works step chips sit under their headings.

**Tests** (node, no browser): `node js/consultation-tests.js`, `node js/checkout-tests.js`, `node js/lander-tests.js`
(the last also scans every file for links, cache version, noindex, external requests and competitor names).
In a browser: `u10LayoutCheck()` from `js/layout-check.js` (labels within 60 px above headings, sideways scroll).

Cache version: `?v=20260994` on every CSS / JS URL.
